4. **Localization and navigation:** duplicate `None` keys in i18n.ts at lines 83 and 181; language narrowing in MessengerChat/support; invalid `view` router parameter in ReportNav.
5. **Lint cleanup:** the 14 fishing hook reports flag event handlers named `useNetBomb`/`useFreeze`. Inspected Crab Cannon implementations contain normal async actions, not React hook calls; rename handlers appropriately and confirm all seven implementations. Address explicit-any/empty catch and hook dependency warnings deliberately. Apply formatting separately to avoid obscuring functional changes.
